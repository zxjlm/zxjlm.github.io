# Theme fonts

Zaxon follows the same pairing used on [pi.dev docs](https://pi.dev/docs/latest): a literary serif for reading, and a pixel mono for chrome.

| Role | Font | License |
| --- | --- | --- |
| Latin body and titles | [Source Serif 4](https://github.com/adobe-fonts/source-serif) | SIL OFL 1.1, reserved name Source |
| CJK body and titles | System serif (`Source Han Serif SC`, `Noto Serif SC`, `Songti SC`) | Host-installed |
| Latin UI, labels, code | [Departure Mono](https://departuremono.com/) by Helena Zhang | SIL OFL 1.1 |
| CJK UI | [Cubic 11 / 俐方體11號](https://github.com/ACh-K/Cubic-11) | SIL OFL 1.1, reserved names Cubic / 俐方體 |

Pixel fonts are drawn on an 11px grid. UI sizes should stay on 11px increments (11 / 22 / 33) and must not be faux-bolded or anti-aliased.

Do not copy Plantin from pi.dev; it is a commercial face. Source Serif 4 is the OFL stand-in and pairs with Source Han Serif for mixed Chinese/English text.
