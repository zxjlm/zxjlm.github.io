## 性能实测

使用 Chromium 156.0.8078.4、390×844、DPR 2、CPU 4 倍降速、75 ms 延迟、下载 6 Mbps、冷浏览器上下文，两套本地服务均为 gzip。外部图床请求被拦截，游记使用同一矢量瓦片夹具。每组 3 次取中位数。 [原始样本与预算](quality-performance.json)

| 页面 | FCP Valaxy → Astro | LCP Valaxy → Astro | 页面响应数 | JS 执行时间 |
| --- | ---: | ---: | ---: | ---: |
| 首页 | 1100 → 616 ms | 1100 → 616 ms | 98 → 25 | 45 → 17 ms |
| 公式文章 | 1348 → 488 ms | 1348 → 772 ms | 99 → 26 | 52 → 19 ms |
| 相册详情 | 912 → 408 ms | 2520 → 408 ms | 100 → 18 | 46 → 14 ms |
| 京都游记 | 1264 → 768 ms | 1264 → 768 ms | 125 → 54 | 293 → 155 ms |

四个场景的长任务数中位数分别为 `1 → 0`、`2 → 0`、`1 → 0`、`3 → 1`。主题按钮点击到第二个动画帧的中位数为 `39 → 34`、`99 → 460`、`29 → 24`、`57 → 80` ms。长公式文章的主题切换在降速实验中较慢，保留为观察项。该测法含样式更新与帧等待，不能用作 INP。真实图片、地图服务、网络和现场流量指标留给线上观察。

## 资源预算

- 静态加载链独立 gzip 后，Astro 首页 39.6 KiB、公式文章 38.5 KiB、相册目录 38.8 KiB、相册详情 41.7 KiB、游记启用地图前 42.1 KiB。优化后的 Valaxy 对应为 228.0、240.2、228.7、228.0、244.9 KiB。
- 首页静态加载链中 Snowlin 2.0 KiB、导览 1.5 KiB，两者共享 Vue 运行时。角色与萤火虫无单独水合。
- 游记地图完整脚本链为 468.1 KiB gzip，其中地图引擎 279.9 KiB、Worker 141.4 KiB。优化 Valaxy 对照为 666.3 KiB。Worker 单列计算，浏览器页面目标的传输统计没有包含 Worker 自身。
- Astro 冷启动 CSS 传输中位数在首页、公式文章、相册详情、游记分别为 12.6、16.8、12.2、23.1 KiB，字体为 463.0、565.9、463.0、513.5 KiB。首轮可见范围及浏览器预取的同源图片合计分别为 82.2、107.5、44.8、107.5 KiB。外部 hero、相册原片及游记照片的全量体积留待线上抽测。
- 回归阈值为首页、文章和相册目录自动 JS 各 55 KiB，详情和游记初始自动 JS 各 60 KiB，完整动态地图 JS 525 KiB。CI 执行 `pnpm benchmark` 并在超出阈值时失败。自动依赖大小、实际传输、执行时间和 LCP 单独记录。

候选版本由 `astro-migration-rc1` 标记。Cloudflare 的部署、HTTP 状态和真实外部资源验收按 [切换清单](cutover-checklist.md) 执行。
