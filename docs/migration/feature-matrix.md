# 阶段 1 · 旧站功能对照

依据 Valaxy SSG、Zaxon 0.1.23 的主题布局和组件，以及优化构建的 Chromium 抽查。生产路径和部署行为见 [基线记录](baseline.md)。

| 范围 | 旧站证据 | 迁移决定 |
| --- | --- | --- |
| 首页、技术、生活、归档 | SSG 有列表和栏目入口。首页最近文章取五篇，技术和生活由主题分类及后备规则判定 | 保留栏目、顺序、总数、链接和视觉。阶段 2 对照实际分组 |
| 分类、标签 | 首页有树形分类、计数及标签链接。111 个详情链接均无 SSG 文件 | 保留索引和分类层级。阶段 2 补详情页并核对旧链接编码 |
| 关于、友链、日程 | 关于有正文。友链显示“友链页面迁移中。”，日程只保留路由与标题 | 保留关于正文、友链提示及日程占位 |
| 文章、目录、前后篇 | `StarterArticle` 渲染正文、发布日期、分类、条件作者卡、前后篇和原文链接。目录在挂载时扫描 h2–h4 | 保留阅读功能和旧锚点，构建时输出目录。阶段 2 核对更新时间和文章附属功能 |
| AI 与来源声明 | `StarterArticle` 按 `ai-assisted` 或 `ai-use` 标签显示 AI 声明。正文末尾及 Markdown 原文有来源声明 | 保留判定、内容及原文链接 |
| Markdown、公式 | 原产物有公式和标题 ID，重复标题有数字后缀，例如 `评价-1` | 阶段 2 比较公式、代码、表格和锚点 |
| 搜索 | 配置启用，Valaxy 生成 Fuse 数据。主题导航和布局没有可见搜索入口 | 记录为旧站功能缺口。阶段 2 按计划增加按需加载的静态搜索 |
| 赞助、社交与导览 | 赞助写在配置中，主题布局无赞助入口。社交入口可见，主题布局在空闲时加载 `FieldFeatureGuide` | 保留社交和导览，赞助界面延后 |
| 订阅与原文 | 3 种订阅格式各 155 条，155 个原文包含来源声明 | 保留入口、条目标识、摘要策略和 `.md` |
| 相册与首页照片 | Argus v1 索引和详情，4 个相册 32 张照片。首页随机取 2 张，精选开关关闭 | 阶段 3 保留单一索引、精选设置和随机取图，静态生成目录与网格 |
| 灯箱 | Zaxon 含键盘、EXIF、焦点恢复和 Live Photo 分支 | 保留交互。阶段 3 用实际样本验证 Live Photo |
| 两篇游记 | `travel` 布局、坐标、动态 MapLibre 及静态缓存读取。提交中无静态地图缓存 | 保留 45 与 43 个地点和正文联动。阶段 3 验证静态生成和失效处理 |
| 主题和装饰 | 明暗切换、移动导航、响应式 hero、Snowlin、萤火虫和装饰角色 | 保留入口和行为。阶段 3 恢复图标与空闲加载 |
| 404、抓取和站点地图 | 有 `404.html`、robots 和 sitemap | 阶段 2 实现真实 404，阶段 5 对照托管状态码和抓取设置 |
