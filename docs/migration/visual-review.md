# 阶段 4 · 本地视觉回归

对照优化后的 Valaxy/Zaxon SSG 和修复后的 Astro 静态构建。Chromium 156.0.8078.4，桌面 1280×900，手机 390×844，分别固定明暗主题。两套构建由独立回环地址提供。浏览器拦截外部请求，hero 和照片使用相同本地插图，游记共用最小矢量瓦片夹具。截图用于比较版式、裁切方式、加载后的界面与控件。真实图床图片清晰度、动态地图实际瓦片和现场设备表现属于线上或实机验收。

原图和接触表保存在本地 `.validation/visual/`。原图名为 `编号-页面-视口-主题-框架.png`，对照图名为 `pair-编号-页面-视口.png`。对照图左列为 Valaxy，右列为 Astro，上排深色，下排浅色。另存了展开的移动菜单、定位至公式和代码的正文，以及已打开的灯箱。

| 步骤 | 页面与截图编号 | 结果 |
| --- | --- | --- |
| 1 | 首页与展开的移动菜单 `01-home` | 延续导航、hero、入口按钮和分类卡片。Astro 新增搜索图标。390px 下四个操作按钮与品牌区域仍完整，关闭后菜单内容不接收焦点。 |
| 2 | 普通文章 `02-article` | 作者、正文、阅读札记和原文入口可见。Astro 新增更新时间，目录取正文标题，旧版运行时扫描还会纳入正文后附加的「文章声明」。 |
| 3 | 公式长文 `03-math` | KaTeX 公式在两种主题和两种宽度可读，正文列及目录布局延续。移动样本的 Astro 正文宽度和可滚动宽度均为 358px。 |
| 4 | 含代码长文 `04-code` | 双主题 Shiki 使用 Zaxon 的代码容器底色和明暗 token 配色。长行可在代码容器中滚动，视口没有横向溢出。旧主题右上角单独显示代码语言，Astro 在 HTML 中保留语言标记。 |
| 5 | 分类索引 `05-categories` | 分类层级缩进和计数标签保留。Astro 将分类条目接入可访问的静态详情页。 |
| 6 | 相册索引 `06-albums` | 双栏桌面和单栏手机布局保留，标题、计数和发布日期可见。插图使用同一张离线夹具。 |
| 7 | 相册详情与灯箱 `07-album-detail` | 网格保留八张照片的顺序。灯箱保留图像、导航与关闭区域，打开后焦点落到关闭控件。独立交互演练覆盖横屏、EXIF 和 Live Photo。 |
| 8 | 京都游记 `08-kyoto` | 两个版本的行程均为 45 处。桌面目录在侧栏，手机移至正文前。地图与行程交互见游记专项截图和本地浏览器验证。 |
| 9 | 大阪游记 `09-osaka` | 两个版本的行程均为 43 处。文章没有正文标题目录，Astro 保留原文入口与完整行程。 |
| 10 | 404 `10-missing` | 两套本地服务均返回 HTTP 404。路牌、返回首页、归档和有历史时的后退操作保留。 |

首轮截图定位了两处回归。Vue 装饰组件的图片导入曾生成对象而非 URL，桌面显示空框。统一为 URL 导入后，角色在截图中正常显示，导览与 Snowlin 使用同一资源方式。代码块曾在浅色主题沿用深色背景，复拍确认代码容器已恢复对应主题配色。桌面文章滚动后恢复了原有返回顶部按钮。所有抽样页面在 390px 和 1280px 视口均无页面级横向滚动。
