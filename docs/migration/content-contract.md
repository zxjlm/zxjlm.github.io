# 阶段 1 · 内容兼容契约

| 字段或出口 | 契约 |
| --- | --- |
| 文章 ID 和路径 | 相对 `pages/posts/` 的路径去掉 `.md`，保留大小写。正文为 `/posts/<id>`，原文为 `/posts/<id>.md`。重复或只靠大小写区分的冲突应报错 |
| 日期 | 接受斜线或短横线、未补零的年月日和显式时区。文章无时区日期按 Asia/Shanghai 解释，带时区值按写明的偏移解析，展示转回 Asia/Shanghai。空 `updated` 视为缺省。错误日期报告文件及字段 |
| 排序与分组 | 按发布日期倒序，保留 Valaxy 的 `top` 置顶优先级，当前基线无置顶样本。同一优先级和时间以文件名排序。技术/生活优先用已配置分类，后备规则按旧主题核对 |
| 分类和标签 | 标量分类为一级，数组为有序层级。空分类进入 `Uncategorized`，父级计入子级文章。标签保留原文、大小写及成员关系。名称和链接编码按 [URL 清单](url-inventory.json) |
| 草稿与旧状态 | 布尔 `draft: true` 从页面、列表、集合、搜索、订阅和原文过滤。旧 `cid`、`slug`、`status`、`hidden` 及缩略图偏好字段保留在原文，路由与发布过滤忽略这些字段 |
| 摘录 | 列表优先使用显式摘要。订阅沿用 Valaxy 的 `<!-- more -->` 分隔摘录，缺失时取正文前 100 个字符渲染 Markdown，并追加全文链接。搜索可生成展示摘要 |
| 声明与原文 | 对标签 `ai-assisted`、`ai-use` 忽略大小写判断 AI 声明。正文末尾保留来源声明。原文导出保留 frontmatter 和正文，结尾追加声明及链接 |
| 标题锚点 | 保留 Markdown 生成的 ID 及手工 ID，重复标题沿用旧数字后缀。目录链接指向静态正文实际 ID。以 Valaxy 产物和现存内部深链对照 |
| 相册 | 识别 Argus `schema_version: 1`。索引为 `/albums/index.json`，详情路径由 `manifest_path` 指定。保留 ID、slug、图片 URL、照片顺序和可选 Live Photo 元数据 |
| 订阅标识 | Valaxy 优先使用显式 `id`，缺省为完整文章 URL。基线三种格式的 155 个 ID/GUID 均等于完整文章 URL，区分大小写 |
| 订阅时间 | 以实际旧 feed 为对照。旧 YAML 和 feed 序列化与文章展示规则有差异。基线 155 条 JSON Feed 的 `date_modified` 均等于 `date_published`。例如 VPS 文章 YAML 写作 `2026-07-14 18:39:13`，旧 JSON Feed 序列化为 `2026-07-14T18:39:13.000Z`。三种格式的本地条目已逐一核对一致，线上样本待复核 |

同一份公开文章集合提供页面、列表、标签、搜索、订阅和原文。 [基线与归档位置](baseline.md)
