## 搜索行为

`/search/` 由导航栏的搜索按钮打开。支持连续中文短语和空白分隔的多关键词，匹配标题、渲染正文、分类和标签，标题匹配优先。首次提交非空查询后才请求同源 `/search-index.json`，重复查询复用索引。查询写入地址栏的 `q` 参数以支持分享及重载。键盘可用 Enter 提交，用方向键聚焦结果，Esc 返回输入框，用 Enter 打开结果。

本地索引含 155 篇公开文章，每篇均有正文文本。索引为 1,098,424 字节，独立 gzip 压缩为 468,828 字节。该数据只在搜索时传输。禁用 JavaScript 时搜索页提供归档入口。

在 `node scripts/serve.mjs dist 4860` 运行期间，执行 `node scripts/verify-search.mjs`。已用 390px Chromium 验证首次请求边界、中文标题与正文、英文正文、查询重载、无结果状态和键盘跳转。测试拦截第三方请求。
